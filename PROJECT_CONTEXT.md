# CampusConnect

## Overview

CampusConnect is a modern social networking platform exclusively for college students.

The application allows students to connect with classmates, share updates, discover events, build their profiles, and communicate with other students in a clean and modern interface.

The primary goal is to create a responsive, production-quality web application using React, Vite, Tailwind CSS, Firebase Authentication, Firestore, and Firebase Storage.
